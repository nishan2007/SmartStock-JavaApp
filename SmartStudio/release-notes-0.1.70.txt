SmartStudio 0.1.70 (1070) - Windows update only.
Layout, print setup, picture and text settings now live directly in the ribbon. Measurements default to inches. Layout has a floating scrollable Layers list with persistent hide/show, ordering and deletion. Data records use the full editor window and support deleting fields. Font family and size editing is fixed, with a font style dropdown listing real installed/shared font faces. Template print setup, custom fields and records remain saved with each template.
Requires an existing SmartStudio installation; Java runtime and AI model weights are excluded. Shared-template record saving and upload-based 24-hour Photo Queue deletion require the updated SmartStock store server. This Studio update does not update or restart the store server.
