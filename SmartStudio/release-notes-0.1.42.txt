Adds multi-object selection to template canvases: Ctrl/Shift-click toggles objects, dragging empty space selects a group, and Ctrl+A selects all. Selected objects move together by dragging or arrow keys and can be deleted together; Undo restores group edits. Layer-table multi-selection stays synchronized with the canvas. Locked publication objects are protected from moving, resizing, inline text editing and deletion.

Adds Recolour picture to the contextual picture toolbar in Business Cards, Labels and badge artwork. Preview tinting, grayscale, or replacement of a chosen colour with tolerance and optional shading preservation. Click the original preview to sample a source colour. Applied edits preserve image dimensions, transparency and placement, change only the selected artwork, save into existing template formats and support Undo. Personal badge-photo fields remain separate from template artwork.

Adds Picture inks to the Risograph dialog. Assign one or several picture objects to a specific ink, preserving grayscale tones, transparency, cropping, rotation and stacking while keeping the original template unchanged. Unassigned objects use automatic palette separation. Explicit assignments stay isolated even when inks have the same colour; disabled/removed ink assignments block output until corrected. Includes the matching SmartStock 1.1.44 client library; no new store-server API or database migration is required.
