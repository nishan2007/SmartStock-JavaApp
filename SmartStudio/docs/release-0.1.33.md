# SmartStudio 0.1.33: selection-aware text formatting

Adds a top formatting toolbar in badges, business cards and labels. Select a text object to change font family, point size, size up/down, bold, italic, underline, strikethrough, text colour, outline enable/colour/width. Non-text selections disable controls. Narrow windows scroll the toolbar horizontally. Design selection survives formatting and inline edit commits.

Styles persist in local template archives and participate in undo/redo. The common publication renderer supports normal, fitted imported text and WordArt decoration; native badge rendering uses the same stored style properties. Changing font size in fitted imported text switches it to sized text; WordArt scales its dimensions when the point size changes. Original source Publisher files are untouched. Fonts must be available on each client.

Server 1.1.40 accepts and validates the new badge style properties. Sharing badges that use new italic/underline/strike/outline styles requires that server update. Default style fields are omitted from shared badge JSON so ordinary saves remain compatible with earlier template servers. Card/label archives carry their styles and require the current rendering client on every editing computer.
