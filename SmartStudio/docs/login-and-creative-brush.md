# Approved login and Creative Brush identity

Published in SmartStudio 0.1.72 as a verified Windows quick update. The selected login mockup and Creative Brush v4 vector were handed off from the design conversation on 23 October 2026.

The login uses a centered rounded white card, warm-white background, plum company header, the Creative Brush app icon, labelled staff identifier and password/PIN inputs, a purple Sign in action, NFC area, cached-template action with the existing temporary/unsavable limitation, connection settings and restrained footer. A scrollable card keeps actions reachable at small logical heights. The company/store logo and app icon are separate: configured branding appears in the login and editor headers with its aspect ratio preserved; a store without a usable logo gets its company name rather than the app icon. Before store branding is loaded, the existing bundled Deckers company logo remains the default.

Authentication still calls the same LAN credential and badge-PIN APIs. Badge reading still uses the same generated-credential policy and automatic listener. NFC state is based on real pairing, reader detection and capture outcomes; no illustrative connected status is assumed. Manual sign-in fallback, password clearing, server permissions and offline restrictions remain in place. Password visibility can be toggled and resets when the secret is cleared.

The exact approved vector is `src/main/resources/gy/deckers/studio/icons/SmartStudio.svg`.
SHA-256: `9d1637b8bca63566e0577a001c4f83cf7da7979d2f99c05aec2ca660091a1db3`.
It is vector-only, with no embedded raster. The SVG was copied without changes. PNG sizes 16–1024, seven-size Windows ICO and a PNG-chunk macOS ICNS were generated from it. Light/dark compatibility filenames use the same approved artwork. Window identity uses the exact seven small PNG sizes, and the login card uses the same icon. Existing Windows jpackage/Inno Setup icon references consume the updated ICO for executable, shortcut and setup identity. Generation tooling uses build-time sharp plus the existing Java icon-packaging entry point; no runtime rendering dependency was added.

Validation: full Studio package/test build ran 281 tests with no failures/errors and one skipped. Focused login/NFC tests after the final password-mask reset passed. Tests check manual fallback, visibility reset, labelled inputs, company-logo ratio, independent app icon sizes, PNG alpha, ICO image payloads and ICNS/SVG resources. Login component renders were reviewed at 1366×768 and 1920×1080, with a 910×512 scrollable fallback. The compiled app startup check passed in an isolated development profile. Security and whitespace checks passed. Actual paired authentication, NFC reader/PIN operation, installed Windows icon caching/shortcuts, native macOS packaging and manual DPI/accessibility checks remain separate verification steps. No live store, device, service or database was changed.

Preview evidence is in `target/approved-login-proof` and the design report's `visual-refinement.html#login`. Synthetic-company renders used by the automated branding test are labelled by their test fixture and are not presented as real store branding.
