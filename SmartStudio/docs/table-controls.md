# Table controls

The Business Cards, Labels, Bill Books, Banners and Vinyl workspaces provide
**Insert > Insert table…**. Set row and column counts, enter cell text, then Apply.
The table becomes part of the current document; Ctrl+S updates its existing file
or server template using the normal save permissions and conflict checks.

Select a table cell and choose **Table > Edit table…** to edit an existing table,
including native Publisher tables imported as editable cells. Controls include:

- Insert rows above/below and columns left/right; delete a row or column.
- Set total row/column counts, retaining the table's overall dimensions.
- Edit cell text, merge a rectangular selection, or split a merged cell.
- Set table position and size in millimetres, individual row heights and column
  widths, or distribute rows/columns evenly.
- Choose all borders, outside borders or no borders, with line width and colour.

Apply commits one undoable document change. Cancel discards the draft. Existing
cell fonts and artwork are preserved; edited text uses the cell's font. The
existing Text format controls can format selected text cells on the canvas.
**Table > Select whole table** selects the cells and borders together for moving
or copying. Pasted tables have independent identities and stay editable.

Table editing supports up to 100 rows, 100 columns and 2000 cells, subject to the
publication's overall object limit. Unlock and unrotate a table before editing.
Raster-only tables remain pictures and cannot be edited as cells.

Validation includes archive round trips, rendered bottom borders, imported cell
geometry, unrelated artwork preservation, row/column edits, merged cells,
independent copies and undo/redo. Installed-app and physical printing checks are
separate from source tests.
