Proposed behaviour and required fields

Home default · Save As preview · Rename preview · File information

CommandFields / choicesResult
Save AsNew filename, destination (local folder or shared template library), folder/library, template format; print setup, field schema/records and hidden-layer state included.Create a separate file/template and continue editing the new copy. Original remains intact. Confirm before replacing an existing name.
RenameNew name; current folder/library, extension and format shown read-only.Rename the active file or shared template label in its current location. Keep its content and identity. Detect conflicts; shared rename needs write permission. An unsaved draft uses Save As first.
New / Open / RecentWorkspace/template choice, file picker, recent location and availability.Confirm unsaved changes before replacing the active document. Recent entries are scoped to the current store/profile.
Save / Export / PrintCurrent filename/location; export format and page range; existing print setup and print-content modes.Save keeps the current target. Exports do not rename or replace the working template. Print preserves each workspace’s supported workflow.
File info / Import / CloseWorkspace, name, location, size, pages, save status; supported import formats; save/discard/cancel on close.File info is read-only. Import reuses supported workflows. Close returns to the workspace chooser. Account/settings remain in the existing Account menu.

Native formats remain workspace-specific (.sspub or .sstbadge); PDF/PNG are exports. Photo assets/fonts stay embedded or linked according to the existing template format. Badge personal photos and print-record values retain their existing privacy/retention rules. Shared saving/renaming is unavailable offline or without write permission. Do not show a successful save until the current verification checks pass. Ctrl+S = Save; Ctrl+Shift+S = Save As; Esc / Back to Home exits File without changing the document. Specialized options appear only where supported.
