# Magicard 300 manual front and back printing

Install the Magicard 300 Windows driver and select its card paper size and the
orientation matching your template. On the printer, enable Hand Feed Mode to use
the front slot. Configure the driver for single-sided printing.

In Badge Cards, open or edit the front design. Choose **Choose back template**
and select a saved `.sstbadge` design for the reverse. Front and back must have
the same dimensions and orientation. Matching data fields on the back use the
current front's entered details and photo; review the back preview before printing.
Create the back with the normal template editor and save it before opening the front.

Enable **Magicard 300: front + back (manual flip)**, then use **Print** or
**Ctrl+P**. This mode prints one card at a time and forces one copy and single-sided
jobs. Choose the Magicard in the printer dialog. After the front job is sent, wait
for the card to physically finish and eject. Flip and reinsert the same card,
then choose **Print back**. The back uses the same printer and paper settings.
Cancel stops the reverse job but cannot undo the front job already sent.

Use a test card to verify feed orientation, which face prints, back rotation,
alignment, and actual card dimensions before printing production cards. Windows
job submission is not a sensor confirming that a card has finished printing.
Driver, installed application, and physical printer verification remain required.

References: [Magicard Hand Feed Mode](https://support.magicard.com/support-solution/hand-feed-mode/)
and [Magicard 300 user guide](https://support.magicard.com/support-solution/user-guide-magicard-300/).
