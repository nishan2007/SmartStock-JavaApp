# Optional names and text on shirts

1. Select the shirt and colour. Set **Quantity**, or use **Sizes and quantities…**
   to enter the quantity for each size.
2. Open **Print Add-ons**. Enter the shared description, colour, and charge.
   Enable **Different names / text per shirt (optional)** and click
   **Add Print Add-on**.
3. Enter the individual text beside each size and shirt number. For example,
   five Small and four Medium shirts produce five Small fields and four Medium
   fields, numbered separately. Blank fields keep the shared description.
4. Click **OK**, then **Done**, and **Add Line**.

To change names before adding the line, select the add-on and click
**Names / per-shirt text…**. If quantities or sizes change, review that editor
again; increasing quantities preserves existing names and adds blank fields.
Reducing quantities requires reviewing the remaining fields before submission.

The cart summary groups the shirts by size and lists their individual text.
**Show cart lines** displays every shirt with its size, colour, number, and
add-on description. Editing a shirt set restores all its names. Hold/Resume
preserves the shared descriptions and the individual text.

Each saved shirt retains its own add-on description for staff order details and
customer slips. Personalization does not change the add-on charge or quantity.
Leave the option off when every shirt uses the same description.
