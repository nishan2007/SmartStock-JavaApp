# Dedicated staff photo uploader

`https://pic.deckers.gy/` is a dedicated Cloudflare custom domain on the existing managed storefront connection. The root serves only the phone queue uploader. Shop and internal routes on this hostname return 404. Camera and gallery inputs use HTTPS and no-referrer/no-store policies; uploads forward only to the paired store origin with the existing server-side origin credentials. Phone grants do not permit reading photos or administering SmartStock.

Persistent pairing requires SmartStock 1.1.43 and SmartStudio 0.1.41. In Photo Queue choose **Pair staff phone / QR**, give the phone a name and scan the private QR once. The phone saves its upload-only grant in browser local storage; subsequent visits to pic.deckers.gy return directly to the uploader. Browser private mode or clearing storage requires pairing again. Multiple paired stores can be selected on the phone. Staff use **Paired phones** to revoke access at the store server. Forgetting on the phone removes the browser copy; revocation on SmartStudio invalidates the server grant. Existing queued photos are unaffected by revocation.

Persistent grants have no time expiry and are stored as hashed tokens with a separate phone ID/name. Store-scoped authenticated staff operations issue/list/revoke grants; listing never returns tokens. Each store can have up to 30 active paired phones. The existing 12-hour temporary grant behavior is preserved. Personal photos remain in the local store queue and retain the existing 24-hour deletion deadline after confirmed printing. Passport Pictures selects from this shared queue.

Availability: the public uploader page is hosted by Cloudflare; receipt of photos requires the store server, internet and origin connector online. A user-scoped background watchdog starts at Windows sign-in, watches only the separate storefront connector PID and retries after failure. It does not restart SmartStock. The computer must remain powered on and signed in; this is not a Windows system service or a guarantee of uploads while the store is offline. Failed uploads retain the selected photo for retry.
