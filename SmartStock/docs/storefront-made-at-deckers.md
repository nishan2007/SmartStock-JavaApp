# Made at Deckers project publishing

The store server owns portfolio drafts in `storefront.projects`. A completed or delivered custom order can be selected in **Orders → My Orders → Add to Made at Deckers**. The action creates or reuses a private draft tied to that order at the same store. It copies no customer text, artwork, notes, or order price.

Staff with `COMPANY_PREFERENCES` manage the draft in **Company Preferences → Online Store → Made at Deckers**. Enter approved public title, description, category, materials, production method, customization, tags, and optional starting price. Upload an approved JPEG or PNG cover photo under 1.3 MB. Set the status to **Published** or **Featured** only after reviewing the photo and copy. **Archived** removes a project from the next public snapshot. The server checks this permission and the required fields independently of the UI.

Only published or featured projects with an active approved cover asset enter the synchronized storefront snapshot. The public catalog contains a strict project field list and a cover presence indicator; source order IDs and image storage references remain private. The image endpoint serves a project cover only when the project is in that store's published snapshot.

Website visitors can browse and filter published projects and open a project page. **Make something like this** opens a guided quote request with the published project's title, category, materials, production method, and customization context attached by the store server. The customer enters changes, quantity, optional size, color, material, phone, and desired date. The request is private, requires a verified website account, and is stored only by the selected local store. Retrying the same request identifier cannot create a second request. Staff with `MANAGE_CUSTOM_ORDERS` review and update its status under **Company Preferences → Online Store → Custom requests**. The customer sees the status in their account.

Customers can attach up to five JPEG, PNG, PDF, STL, OBJ, or 3MF reference files, 4 MB each. The files are stored in the private `deckers-creative` bucket and in the server's local image mirror. The browser never receives a storage credential or direct bucket URL. Staff with `MANAGE_CUSTOM_ORDERS` can save a file from the request queue through a separate authenticated LAN read endpoint. The private bucket has a restrictive policy that denies direct anonymous and customer access even if a broader Storage policy is present.

The quote request is not a priced order. Automatic project pricing, interactive model preview, proof approval, and conversion into a SmartStock production order remain future work. Complete the live store, backup, installed-app, and mobile checks before treating the workflow as production verified.
