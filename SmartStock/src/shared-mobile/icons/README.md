# Deckers workspace icon set

Fourteen 192 × 192 PNG assets for the approved lavender/purple/orange home screen. Keys match DeckersWorkspace.ICONS and the existing app catalogue. Generated as individual raster assets from the selected mockup; transparent margins normalized and images resized for mobile delivery. Network badges are rendered separately from the server-provided localOnly flag.

The shared logo and signed-in employee photo remain separate existing assets. Source mockup and visual/interaction evidence are documented in repository-root design-qa.md. Do not replace an app icon with a screenshot of an entire UI or bake network badges into the artwork.
